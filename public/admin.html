User Management

Manage M365 user access and roles for the AR Portal. Users sign in with their ECF Microsoft account.

Role Definitions

What each role can do in the portal

⚡ Admin
Full access. Manage users, assign roles, see all invoices, add notes, create PTPs, refresh data.
👔 Manager
View all invoices. Add notes and PTPs. Cannot manage users or change roles.
📋 AR Specialist
View and work invoices. Add notes and PTPs. Filtered to assigned locations/customers.
👁 Viewer
Read-only. Can view invoices and notes but cannot add notes, PTPs, or modify anything.
